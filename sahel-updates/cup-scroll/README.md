# حرکت لیوان با اسکرول

فایل `../sahel-cup-scroll.zip` را در پیشخوان وردپرس، از **افزونه‌ها ← افزودن ← بارگذاری افزونه** نصب و فعال کنید. نام افزونه: **حرکت لیوان قهوه ساحل با اسکرول**. پس از فعال‌سازی صفحهٔ اول را تازه کنید؛ تنظیم جداگانه لازم نیست.

اسکرول رو به پایین، لیوان را به پایین منتقل و به‌آرامی می‌چرخاند؛ با برگشت اسکرول، حرکت معکوس می‌شود. شدت حرکت در موبایل کمتر است. تنظیم کاهش حرکت سیستم کاربر رعایت می‌شود. نیازی به Elementor یا jQuery نیست و محصولات/دیتابیس تغییری نمی‌کنند.

افزونه برای همان تصویر لیوان قالب قهوه ساحل ساخته شده است. روی صفحهٔ فاقد این تصویر، کاری انجام نمی‌دهد. مرورگر واقعی در اندازه‌های دسکتاپ 1440، تبلت 820 و موبایل 390 تست شده؛ نتیجه در `test-report.json` و کد در `source` است.

مخزن خصوصی است؛ برای دانلود ZIP، با حساب مجاز وارد GitHub شوید، صفحهٔ فایل ZIP را باز کنید و **Download raw file** را بزنید.
