# تعاملات قهوه ساحل

فایل `../sahel-interactions.zip` را در افزونه‌های وردپرس بارگذاری و فعال کنید، سپس کش سایت را پاک کنید.

- ورود نرم عنوان‌ها و کارت محصولات با اسکرول؛ حرکت کوتاه‌تر روی موبایل.
- عمق و چرخش جزئی کارت با حرکت ماوس، بزرگ‌نمایی ملایم تصویر، واکنش دکمه‌ها.
- اصلاح دکمه جمع‌شونده محصولات نیز داخل همین افزونه است؛ افزونه جداگانه اصلاح دکمه لازم نیست.
- با افزونه حرکت لیوان قابل استفاده است؛ حرکت لیوان را جایگزین نمی‌کند.
- بدون تغییر محتوا، ساختار محصولات یا اسکرول طبیعی مرورگر؛ رعایت تنظیم کاهش حرکت.

تست مرورگر روی سناریوهای دسکتاپ، موبایل و کاهش حرکت انجام شده است. تست روی سایت زنده شما انجام نشده است.
