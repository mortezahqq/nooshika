# طراحی جیاواز

نسخهٔ طراحی صفحهٔ اصلی با تصاویر، فونت‌ها و محتوای فایل ارسالی.

- `index.html`: نسخهٔ مستقل؛ آن را دانلود و در مرورگر باز کنید.
- `jiawaz-design.zip`: بستهٔ کامل طراحی شامل فایل HTML، منابع تصویری و فونت‌ها و اسکریپت اسلایدرها. فایل ZIP را استخراج و `index.html` را باز کنید.

این تحویل صرفاً طراحی است.
