# Kasebi Process Hub — نسخهٔ ۱.۳.۵.۷

لینک فاکتور در پیامک‌های سفارش مشتری اصلاح شد. پیامک «کسری»، «ارسال باقیمانده» و «تکمیل سفارش»، فاکتور معمولی همان سفارش را باز می‌کنند. پیامک خودکارِ ارسال کالا و پیامک ثبت قطعی سفارش نیز به همین فاکتور متصل شدند.

## اصلاح لینک و نوع چاپ

- دکمه‌های دستی، لینک قالب معمولی «فاکتور فروش» را می‌سازند. شناسهٔ خود سفارش در لینک استفاده می‌شود تا پیش‌فاکتور یا سفارش دیگری از همان مشتری باز نشود.
- پیامک خودکارِ پس از ارسال کالا، به‌جای صفحهٔ اصلی پنل، لینک فاکتور همان سفارش را دارد.
- آدرس فاکتور با پارامترهای کامل نگهداری می‌شود؛ پاک‌سازی مخصوص متن پیامک، جداکننده‌های آدرس را تغییر نمی‌دهد.
- سفارش دارای اقلام ثبت‌شده، حتی پیش از تخصیص موجودی انبار، از طریق قالب معمولی قابل مشاهده و چاپ است. نمایش فاکتور به تخصیص یک ردیف انبار وابسته نیست.
- آدرس فاکتور از آدرس همان سایت گرفته می‌شود؛ این تغییر برای هر دو پنل مقیم‌زاده و هورسان قابل استفاده است.

## رفتار دکمه‌های پیامک

دکمه‌ها با همان جایگاه، رنگ و طراحی قبلی باقی مانده‌اند. درخواست ارسال، اعتبار فرم، سفارش، مشتری و دسترسی کاربر را بررسی می‌کند. ویزیتور فقط برای سفارش مجاز خودش می‌تواند پیامک ارسال کند.

اگر سفارش یا شمارهٔ مشتری موجود نباشد، دریافت پیامک برای مشتری غیرفعال باشد یا سامانهٔ ارسال استثنا برگرداند، پیام موفقیت نمایش داده نمی‌شود. خطای درخواست، پنجرهٔ آیتم‌ها و فهرست را خالی نمی‌کند. کلیک تکراری روی همان دکمه هنگام درخواست نیز مهار شده است.

## نصب و استفاده

این ZIP را از بخش بارگذاری افزونه‌های وردپرس جایگزین نسخهٔ فعلی کنید و صفحه‌های باز پنل را تازه کنید. سپس از «آیتم‌های سفارش»، پیامک موردنظر را مانند قبل ارسال کنید. لینک پیامک تازه، فاکتور معمولی همان سفارش را باز می‌کند.

برای مواردی که قبلاً لینک نادرست یا فاکتور رسمی پیامک شده است، پس از نصب پیامک را دوباره ارسال کنید؛ متن و لینک پیامک‌های تحویل‌داده‌شدهٔ قبلی قابل تغییر نیست.

این نسخه ادامهٔ ۱.۳.۵.۶ است و امکانات قبلی، از جمله پیش‌فاکتورهای مستقل و ثبت کرایه از پرداختی‌های مشتری را حفظ می‌کند. قالب معمولی موجود برای پیامک استفاده شده است؛ فایل قالب‌های چاپ و استایل پنل تغییر نکرده‌اند.

## اعتبارسنجی

۳۰ بررسی تولید پیامک و دسترسی، ۱۰ بررسی HTTP شامل بازکردن مستقیم لینک توسط مشتری و سفارش بدون تخصیص موجودی، ۱۰ مسیر مرورگر Chromium برای سه دکمه و مشاهدهٔ فاکتور، و ۵ بررسی تکمیلی شامل آدرس هر دو سایت و حفظ گردش‌های مالی و موجودی موفق بودند. مسیر خودکار ارسال کالا و ثبت سفارش نیز بررسی شد. بررسی نحوی ۲۳۵ فایل PHP و JavaScript تغییرکرده موفق بود.

تمام پیامک‌های آزمایشی توسط درگاه شبیه‌سازی‌شده در محیط محلی ثبت شدند؛ پیامک واقعی به مشتریان ارسال نشد. وضعیت تحویل اپراتور و قالب ذخیره‌شدهٔ سرویس پیامک در این آزمون محلی بررسی نشده است. بسته روی سایت مشتری نصب نشده و هیچ دیتابیس یا فایل خصوصی مشتری در این انتشار قرار ندارد.
