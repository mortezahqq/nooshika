# نسخه ۱.۶.۱ — تاریخ ارسال در سفارش‌های مشتری

در جدول سفارش‌های هر مشتری، ستون «تاریخ ارسال» بلافاصله کنار «تاریخ ثبت» اضافه شده است. این ستون در مشخصات مشتری، نمایش مشخصات مشتری برای ویزیتور و فهرست سفارش‌های خود مشتری نمایش داده می‌شود و از همان طراحی و قالب تاریخ فعلی افزونه استفاده می‌کند.

برای سفارش‌های دارای چند ارسال، تاریخ آخرین ارسال معتبر نمایش داده می‌شود. ارسال لغوشده و ارسال بدون مقدار واقعی در این تاریخ محاسبه نمی‌شوند. برای ارسال‌های قدیمی که زمان ارسال جداگانه ندارند، زمان ثبت همان سابقه ارسال استفاده می‌شود؛ تاریخ ایجاد سفارش جایگزین تاریخ ارسال نمی‌شود. سفارش بدون ارسال معتبر با عبارت «ارسال نشده» مشخص می‌شود.

نمایش تاریخ در صفحه‌های بعدی و هنگام فیلتر وضعیت سفارش نیز برقرار است. محدودیت مشاهده سفارش‌های ویزیتور حفظ شده است. هیچ سابقه یا تاریخ ذخیره‌شده‌ای تغییر نکرده و امکانات نسخه ۱.۶.۰، از جمله کد محصولات و فرم سالن تولید، عیناً باقی مانده‌اند. تغییر دیتابیس یا آماده‌سازی تازه لازم نیست.

آزمایش محلی نمایش هر سه جدول، تاریخ آخرین ارسال، ارسال قدیمی، ارسال لغوشده، سفارش بدون ارسال، فیلتر وضعیت، صفحه دوم و محدودیت ویزیتور موفق بود. نسخه روی سایت اصلی نصب نشده است.
