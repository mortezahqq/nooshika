# نسخه آزمایشی بنکداری کاسبی ۰٫۲۱٫۰

فایل فشرده برای نصب از پیشخوان وردپرس آماده شده است. راهنمای کامل در داخل بسته، پوشهٔ مستندات و فایل زیر قرار دارد:

`docs/gold-wholesale.md`

این نسخه آزمایشی است و ابتدا باید روی سایت آزمایشی نصب شود. ماژول «بنکداری و کیف طلایی» به‌صورت پیش‌فرض خاموش است و به ووکامرس نیاز دارد.

اتصال واقعی آب‌شده‌فروش و سامانهٔ بسته‌بندی، پرداخت خودکار کیف طلایی و تطبیق خودکار دفترها هنوز تکمیل نشده‌اند. عملیات کیف و خرید جایگزین در این مرحله با تأیید دستی مدیر انجام می‌شوند. جزئیات محدودیت‌ها در راهنمای داخل بسته آمده‌اند.

بسته شامل تنظیمات محیط آزمایش، اطلاعات ورود یا پروندهٔ پیکربندی وردپرس نیست.
